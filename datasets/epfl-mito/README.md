## 🧾 Dataset overview

The EPFL electron-microscopy resource is a high-resolution 5 × 5 × 5 μm³ volume from the CA1 hippocampus. The page provides separate annotated subvolumes for training and testing; the literature entry count is not the subvolume count.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
