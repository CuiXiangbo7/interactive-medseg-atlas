## 🧾 Dataset overview

The Longitudinal MS Lesion Segmentation Challenge uses MRI acquired at multiple time points from people with multiple sclerosis. Manual lesion labels from two raters support both segmentation-accuracy and lesion-evolution evaluation.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The challenge site links separate training and test archives and includes longitudinal MRI from multiple time points. The paper-entry image count (42) is preserved as the paper entry; it should not be interpreted as the number of participants or annotation files.
