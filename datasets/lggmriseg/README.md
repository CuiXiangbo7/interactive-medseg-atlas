## 🧾 Dataset overview

The Kaggle entry provides brain MRI and manual FLAIR-abnormality masks associated with lower-grade glioma cases. TCIA maintains the underlying TCGA-LGG image collection and a separate record for the related segmentation labels.
> **Source note:** The Kaggle image/mask package and the TCIA collection and segmentation records are related but distinct release records.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
