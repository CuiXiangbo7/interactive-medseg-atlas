## 🧾 Dataset overview

NIS3D is a dense 3D nuclei-segmentation benchmark. Its official Zenodo card reports more than 22,000 manually annotated cells and links the benchmark repository for acquisition details and annotation examples.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The Zenodo record describes more than 22,000 manually annotated cells. The linked repository provides benchmark details and download instructions.
