## 🧾 Dataset overview

AortaSeg24 addresses 3D segmentation of the aorta, its branches, and clinically relevant aortic zones in CTA. The challenge focuses on anatomy needed to describe aortic disease and plan branch-vessel procedures.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

The official challenge page describes a 100-volume CTA challenge release. The paper entry lists 50 images; this is retained separately from the challenge-wide count and should not be read as the full release size.
