## 🧾 Dataset overview

BBBC032 contains microscopy images of mouse-embryo blastocyst cells with manually annotated reference labels. The collection is intended for benchmarking cell-level image analysis.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
