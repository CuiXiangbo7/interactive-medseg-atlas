## 🧾 Dataset overview

The Cardiac Atlas Project LV challenge provides MRI cases for left-ventricle segmentation. The project page explains the benchmark and links its challenge data and publication.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The Cardiac Atlas Project page describes 100 training and 100 test cases sampled from the DETERMINE cohort. The paper-entry count of 1,637 MRI images uses a different image-level scope and is preserved separately.
