## 🧾 Dataset overview

The Duke Liver Dataset contains routine-protocol liver MRI series from 105 subjects, including 2,146 series in the series-classification grouping and a separate liver-segmentation grouping. Images span multiple sequences, contrast phases, and orientations; the Zenodo record marks the dataset restricted.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

Zenodo describes over 2,000 anonymized MRI series from 105 subjects, including 2,146 series for series classification and a 310-image liver-segmentation subgroup. The record is restricted access.
