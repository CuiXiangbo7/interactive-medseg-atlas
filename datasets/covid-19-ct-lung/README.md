## 🧾 Dataset overview

This Zenodo release provides 20 labelled COVID-19 CT scans with left-lung, right-lung, and infection masks. Two radiologists annotated the scans, with review by an experienced radiologist.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
