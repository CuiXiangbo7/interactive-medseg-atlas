## 🧾 Dataset overview

ATM’22 is a multi-site, multi-domain airway-tree modeling challenge using CT. The official challenge describes airway segmentation as a prerequisite for quantitative analysis of pulmonary diseases.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official site documents a 300-case training release and a separate long-term hidden test phase with 150 cases. Additional validation phases and file access depend on challenge registration and release rules.
