## 🧾 Dataset overview

Prostate158 is a prostate MRI segmentation resource with gland and lesion labels. The Zenodo training-data record provides the release archive; consult its version metadata and the cited paper for cohort and annotation details.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
