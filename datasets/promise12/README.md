## 🧾 Dataset overview

PROMISE12 was organized to compare automatic and interactive/semi-automatic prostate MRI segmentation. The current Zenodo record contains the challenge archives for training, test, and live-challenge data; use the archive-specific documentation to distinguish labelled cases from evaluation data.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The current Zenodo record provides separate training_data.zip, test_data.zip, and livechallenge_test_data.zip archives. The record does not summarize a single total case count in the landing-page text; use the included manifests and challenge documentation for each archive.
