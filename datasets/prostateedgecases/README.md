## 🧾 Dataset overview

The TCIA Prostate Anatomical Edge Cases collection is intended to assess robustness on challenging pelvic anatomy. The official record describes CT images and prostate, bladder, and rectum structures.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
