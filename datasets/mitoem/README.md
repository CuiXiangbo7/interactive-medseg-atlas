## 🧾 Dataset overview

MitoEM is a large-scale 3D mitochondria instance-segmentation benchmark based on human and rat tissue. The challenge page notes that its v2 annotations correct errors from the earlier release.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The challenge release provides human and rat image volumes. Its v2 annotation page identifies the first 500 slices as train (0–399) and validation (400–499); use the v2 labels because the release notes correct errors in earlier annotations.
