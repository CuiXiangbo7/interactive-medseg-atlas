## 🧾 Dataset overview

MAMA-MIA is a multicenter breast-cancer DCE-MRI benchmark with expert lesion segmentations. Its Synapse record is the cited access point and may require an account or approved data-use access.
> **Source note:** The Synapse record may require user authentication and acceptance of data-use terms before file downloads are available.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
