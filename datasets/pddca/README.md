## 🧾 Dataset overview

PDDCA v1.4.1 contains 48 head-and-neck CT cases from the RTOG 0522 study, with manual labels for organs at risk and bony landmarks. The maintainers identify the resource as a public-domain database and link the full data documentation.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
