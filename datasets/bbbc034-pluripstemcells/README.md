## 🧾 Dataset overview

BBBC034 contains fluorescence-microscopy images of human induced pluripotent stem cells with associated reference annotations. The collection page states a CC BY 4.0 image and ground-truth license.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
