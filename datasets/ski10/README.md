## 🧾 Dataset overview

SKI10 is a knee MRI benchmark for cartilage and bone segmentation. Its challenge page describes the aim of developing and comparing algorithms for these musculoskeletal structures.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
