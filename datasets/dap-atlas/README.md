## 🧾 Dataset overview

DAP-ATLAS is a whole-body CT anatomical-label resource associated with a 142-class atlas. Its public repository links the data and processing material; consult the cited publication for the construction protocol and exact class definitions.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
