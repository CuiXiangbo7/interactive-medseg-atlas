## 🧾 Dataset overview

HVSMR is a whole-heart and great-vessel segmentation benchmark using cardiovascular MRI, with a focus on congenital heart disease. Consult the challenge record for the exact release edition and label definitions.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
