## 🧾 Dataset overview

This task is the Medical Segmentation Decathlon cardiac MRI case: left-atrial segmentation from mono-modal MRI. The challenge frames it as a small-cohort task with substantial anatomical variation.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

Official challenge release: 30 cardiac MRI volumes, 20 training and 10 test. The listed entry count matches the labeled training count.
