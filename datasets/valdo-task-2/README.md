## 🧾 Dataset overview

VALDO Task 2 evaluates cerebral microbleed segmentation on MRI. The official task page specifies a binary mask convention and states that training cases are labelled while test cases are hidden for evaluation.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The task publication describes 20 cases with dot annotations for cerebral microbleeds. Challenge evaluation distinguishes the labelled training data from withheld test data; use the official task instructions for the exact split and label representation.
