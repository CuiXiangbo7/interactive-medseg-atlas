## 🧾 Dataset overview

The NIH lymph-node entry points to the TCIA CT-Lymph-Nodes collection. The TCIA record contains mediastinal and abdominal lymph-node annotations with separate patient groups; this guide preserves the paper entry’s own count and target wording rather than treating it as a distinct imaging collection.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
