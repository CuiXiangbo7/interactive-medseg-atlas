## 🧾 Dataset overview

BrainMetShare provides whole-brain MRI studies with pre- and post-contrast sequences and radiologist ground-truth labels for brain metastases. The Stanford-hosted description reports 156 studies in the resource, while the linked literature entry gives a narrower count.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
