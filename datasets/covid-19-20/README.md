## 🧾 Dataset overview

COVID-19-20 is a post-challenge CT benchmark for segmenting and quantifying lung lesions caused by SARS-CoV-2. The official page links the final challenge publication and data resources.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
