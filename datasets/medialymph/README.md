## 🧾 Dataset overview

The mediastinal lymph-node segmentation resource is derived from chest CT and is distributed with reference labels and associated code through the authors’ repository. The repository describes a five-fold patient-level evaluation; the fold size is not the full cohort size.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
