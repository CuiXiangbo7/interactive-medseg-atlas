## 🧾 Dataset overview

The mediastinal-structure resource uses chest CT with labels for structures surrounding the lymph nodes, including lungs and mediastinal anatomy. The authors’ repository groups these data with the related lymph-node task and provides the corresponding reference files.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
