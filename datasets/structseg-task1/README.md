## 🧾 Dataset overview

StructSeg 2019 Task 1 evaluates organs-at-risk segmentation on head-and-neck CT for radiotherapy planning. The challenge defines 22 OAR structures, including small and anatomically adjacent structures that matter for treatment planning.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official task page describes 50 head-and-neck CT training cases and 10 test cases for the OAR task. The image count shown in the paper entry is the training-set count.
