## 🧾 Dataset overview

The Drosophila ventral-nerve-cord resource is an anisotropic serial-section transmission electron microscopy volume of neural tissue. The public repository distributes image stacks and ground-truth labels for structures such as mitochondria and synapses.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
