## 🧾 Dataset overview

TopCoW is a Circle of Willis vessel segmentation challenge using CTA and MRA. The challenge page describes staged releases of paired angiographic studies and topology-aware anatomical labels.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The challenge released the training set in phases and evaluates CTA and MRA domains separately. The official page records distinct validation and final-test submission periods; use the organizer’s split files rather than the paper-entry image count as a split.
