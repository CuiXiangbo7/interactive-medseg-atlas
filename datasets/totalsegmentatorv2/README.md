## 🧾 Dataset overview

TotalSegmentator provides broad anatomical segmentation labels for clinical CT and MRI. Its official repository describes the current training resources as multi-institutional and heterogeneous in scanner, protocol, and pathology; the published target list and this paper entry can refer to different dataset versions.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The current official repository links 1,228 CT subjects and 616 MR subjects in its training resources. Those repository counts describe the current tool resource and may not be identical to the cohort used in the cited paper entry.
