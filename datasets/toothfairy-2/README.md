## 🧾 Dataset overview

ToothFairy2 is a 480-volume CBCT challenge dataset with 42 maxillofacial classes. Set A overlaps earlier ToothFairy material, while Set B adds 63 wider-field scans and complete upper-teeth labels.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official page reports 480 CBCT volumes: 417 in Set A and 63 new wider-field Set B scans. The 42 anatomical classes are supplied according to the release-specific label files.
