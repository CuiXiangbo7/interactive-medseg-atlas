## 🧾 Dataset overview

CAMUS provides 2D apical two- and four-chamber echocardiography sequences from 500 patients. The official project includes annotations for cardiac structures and was created for segmentation and volume-estimation research.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official project reports 500 patients with apical two- and four-chamber sequences. The downloadable collection has labelled training sequences; the online evaluation platform is closed.
