## 🧾 Dataset overview

The TCIA Pancreas-CT collection contains contrast-enhanced portal-venous abdominal CT acquired at the NIH Clinical Center. The collection includes kidney-donor examinations and selected patients without major abdominal pathology or pancreatic cancer; pancreas masks were manually drawn and radiologist-reviewed.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

TCIA reports 80 participants, studies, and series, with 18,942 DICOM images. The collection summary separately describes 82 contrast-enhanced CT scans from 80 subjects; the paper-entry count of 82 is therefore a scan-level value, not the number of DICOM slices.
