## 🧾 Dataset overview

The TCIA pediatric CT segmentation collection provides CT from pediatric subjects together with organ labels. Consult the collection record for the exact release version, subject count, annotation extent, and reuse requirements.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The TCIA record describes a multi-institutional pediatric CT collection; most subsequent scans were reformatted to 2.0 mm slice thickness before contouring because thin-slice noise made manual annotation difficult. Check the collection record for the exact current case and label files.
