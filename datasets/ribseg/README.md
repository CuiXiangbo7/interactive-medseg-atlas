## 🧾 Dataset overview

RibSeg is a CT benchmark for instance-level segmentation of individual ribs. The original repository now directs users to the HINTLab-maintained project, which is the current source for the dataset and its preparation instructions.
> **Source note:** The repository cited in the source list states that the project moved; use the current HINTLab repository linked here.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
