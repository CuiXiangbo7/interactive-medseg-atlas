## 🧾 Dataset overview

CETUS is a 3D echocardiography challenge for left-ventricular endocardial segmentation. The official challenge page describes manual contours for the training cohort and image-only test sets.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official challenge describes 15 training patients with manual contours and two test groups of 15 patients each without manual contours.
