## 🧾 Dataset overview

ReMIND contains preoperative and intraoperative imaging from patients undergoing image-guided brain-tumour resection. The TCIA record describes MRI, intraoperative ultrasound, and segmentations of relevant tumour/resection structures.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The TCIA record contains several distinct annotation types and counts, including preoperative whole-tumour masks for 113 cases, residual-tumour masks for 58, and resection-cavity masks for 21. These label-specific counts should not be collapsed into one total.
