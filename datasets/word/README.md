## 🧾 Dataset overview

WORD is a large-scale abdominal CT benchmark with 16 organ labels. The official repository provides the dataset version, label files, evaluation materials, and associated clinical generalization work.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

The author repository releases the WORD CT dataset with 16 abdominal-organ labels and provides its case lists and preprocessing instructions. Use the repository version and manifest to determine which labels and cases are included in a particular download.
