## 🧾 Dataset overview

The TCIA CT-Lymph-Nodes collection combines mediastinal and abdominal lymph-node CT annotations. Its record describes 388 mediastinal nodes in 90 patients and 595 abdominal nodes in 86 patients, with point/measurement annotations rather than a uniform volumetric mask for every node.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The TCIA collection reports 388 mediastinal lymph nodes in 90 patients and 595 abdominal nodes in 86 patients. Annotations include coordinates and size measurements; they are not equivalent to one binary 3D segmentation mask per node.
