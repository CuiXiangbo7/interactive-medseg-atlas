## 🧾 Dataset overview

SPIDER is a multicenter lumbar-spine MRI dataset with reference segmentation of vertebrae, intervertebral discs, and spinal canal. Its official record documents the cohort and identifies a separate hidden challenge test set.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The Zenodo record reports 447 sagittal T1- and T2-weighted MRI series from 218 studies in 218 patients across four hospitals, plus a separate hidden challenge test set. The 447 value is a series count, not a patient count.
