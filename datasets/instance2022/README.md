## 🧾 Dataset overview

INSTANCE2022 is an intracranial-haemorrhage segmentation challenge on non-contrast head CT. The official page provides task, data, and evaluation information and records the later public release notice.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
