## 🧾 Dataset overview

This TCIA collection provides imaging and clinical data for soft-tissue sarcoma, including MRI and PET/CT. The associated study investigates radiomic features and tumour characteristics; see the collection record for its contours and access terms.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The TCIA collection describes 51 patients with extremity soft-tissue sarcoma and pretreatment FDG-PET/CT plus anatomical MR sequences. The paper-entry count of 102 images is retained separately from the patient count.
