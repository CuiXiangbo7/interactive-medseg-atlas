## 🧾 Dataset overview

FiloData3D contains synthetic 3D images of single A549 cells with filopodia and cell-level ground truth. The Broad collection states a CC BY-NC-SA 4.0 license.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
