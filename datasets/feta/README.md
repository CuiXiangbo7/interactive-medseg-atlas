## 🧾 Dataset overview

FeTA 2024 provides clinically acquired fetal-brain T2-weighted reconstructions from two institutions. The segmentation task uses seven manually delineated tissue classes and includes neurotypical and pathological cases across gestational ages.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

FeTA 2024 provides 120 training T2-weighted fetal-brain reconstructions from two institutions, with seven manually labelled tissue classes; the challenge page describes 180 test cases.
