## 🧾 Dataset overview

SegThy sub-dataset 2 provides freehand-tracked 3D ultrasound of the thyroid region from routine-care patients. The institutional release describes this alongside the healthy-volunteer MRI/ultrasound cohort and supplies label maps for the available scans.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The source describes 28 healthy volunteers and 186 routine-care patients across the two sub-datasets. The MRI and ultrasound acquisition counts differ substantially; the paper-entry image count must not be interpreted as the number of subjects.
