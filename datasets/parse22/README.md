## 🧾 Dataset overview

Parse22 is a pulmonary-artery segmentation challenge using chest CT. The challenge targets a clinically relevant vascular structure and provides official participation and evaluation information.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
