## 🧾 Dataset overview

MRBrainS18 is a brain MRI segmentation challenge built around multi-contrast structural imaging and tissue delineation. The official challenge record is retained for the source entry; consult its paper and data page for exact protocol and annotation-class definitions.
> **Source note:** The official dataset DOI resolves to the access record; the older challenge page was not readable in this review.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
