## 🧾 Dataset overview

NucMM targets neuronal nuclei in large 3D electron-microscopy volumes. Its challenge materials provide dense instance labels and describe the sub-cubic-millimeter scale of the imaging task.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
