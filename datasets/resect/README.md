## 🧾 Dataset overview

RESECT is a brain-tumour ultrasound dataset paired with MRI and expert tumour annotations. It was created to study ultrasound-based segmentation and image-guided neurosurgical applications; the linked OSF record is the cited access point.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
