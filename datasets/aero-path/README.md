## 🧾 Dataset overview

AeroPath is an airway-segmentation benchmark assembled to include challenging lung pathology. Its official repository reports 27 CT volumes with corresponding airway and lung annotations and links both Zenodo and Hugging Face access routes.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
