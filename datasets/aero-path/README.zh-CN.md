## 🧾 数据集简介

AeroPath 是包含复杂肺部病理情况的气道分割基准。官方仓库报告 27 例 CT 体数据及对应气道、肺部标注，并链接 Zenodo 与 Hugging Face 两种访问入口。

论文条目影像数与官方发布范围分开记录。本图谱不镜像托管影像或掩膜文件。
