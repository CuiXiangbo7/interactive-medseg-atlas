## 🧾 Dataset overview

LIDC-IDRI is a multi-institutional thoracic CT reference collection assembled by seven academic centres and eight imaging companies. It contains diagnostic and screening examinations with radiologist-marked lung nodules; the original XML preserves independent reader marks and malignancy assessments rather than a single consensus contour.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

TCIA lists 1,010 subjects in the collection statistics, while its narrative describes 1,018 cases. The source explains this as a multi-reader CT reference release; this guide preserves both reported scopes and does not infer a training/test split.
