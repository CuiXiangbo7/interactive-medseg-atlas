## 🧾 Dataset overview

ISLES 2015 is a historical ischemic-stroke lesion benchmark based on multi-spectral MRI. Its official portal describes separate sub-acute (SISS) and acute (SPES) tasks and points participants to the VSD platform for registration and data delivery.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
