## 🧾 Dataset overview

The NCI-ISBI 2013 challenge uses axial T2-weighted prostate MRI selected from two TCIA collections and acquired with different field strengths and coil configurations. The TCIA record describes separate training, leaderboard, and final-test partitions.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

TCIA lists 80 subjects and describes three partitions: training, leaderboard, and final test. The record provides T2-weighted axial prostate MRI acquired at 1.5 T and 3 T.
