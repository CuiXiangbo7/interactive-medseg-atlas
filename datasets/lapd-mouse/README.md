## 🧾 Dataset overview

The LAPD Mouse Archive combines mouse-lung anatomy imaging with particle-deposition measurements and downloadable label files. The archive page organizes the data by anatomical representation and provides a data-usage policy.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
