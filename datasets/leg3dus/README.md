## 🧾 Dataset overview

Leg-3D-US is a 3D ultrasound resource for lower-limb muscle and tissue analysis. The official university page provides separate downloads for training, validation, and test data.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
