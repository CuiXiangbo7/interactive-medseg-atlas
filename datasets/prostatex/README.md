## 🧾 Dataset overview

PROSTATEx-2 is a quantitative multiparametric prostate MRI challenge focused on lesions and Gleason Grade Group prediction. The source distinguishes training cases with reference information from a held-out test set without released truth.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
