## 🧾 Dataset overview

The Multi-Centre, Multi-Vendor and Multi-Disease cardiac MRI challenge was designed to measure segmentation performance across acquisition domains. It includes cine MRI from multiple centres and scanner vendors, with left- and right-ventricular and myocardial contours.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
