## 🧾 Dataset overview

KiPA22 is a CTA challenge for joint segmentation of kidneys, renal tumours, arteries, and veins. Its challenge description emphasizes predicting these structures together in one inference.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
