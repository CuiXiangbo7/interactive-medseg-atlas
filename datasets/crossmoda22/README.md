## 🧾 Dataset overview

CrossMoDA is a cross-modality benchmark for vestibular schwannoma and cochlea segmentation. Its 2022 task adapts from contrast-enhanced T1-weighted MRI to high-resolution T2-weighted MRI.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
