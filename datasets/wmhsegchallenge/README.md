## 🧾 Dataset overview

The WMH Segmentation Challenge evaluates white-matter-hyperintensity delineation in brain MRI. The linked dataset DOI is the primary access record; challenge split and file-level label availability should be taken from that release rather than inferred from the paper-table count.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
