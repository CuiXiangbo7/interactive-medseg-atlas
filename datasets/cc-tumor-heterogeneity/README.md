## 🧾 Dataset overview

This TCIA collection contains cervical-cancer MRI and associated imaging/clinical records for studying tumour heterogeneity. Its collection-level page is the authoritative route for the cohort and annotation materials.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
