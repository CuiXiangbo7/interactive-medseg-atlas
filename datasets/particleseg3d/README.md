## 🧾 Dataset overview

ParticleSeg3D is a 3D micro-CT benchmark for mineral particles. Its dataset repository provides the image/label resources and a scalable out-of-the-box segmentation workflow described in the cited paper.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
