## 🧾 Dataset overview

StructSeg 2019 Task 3 evaluates six organs-at-risk on chest CT from patients with lung cancer. The task is framed around contouring structures needed for thoracic radiotherapy planning.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The official task page describes 50 lung-cancer chest CT training cases with six OAR labels and 10 test cases. The paper-entry count corresponds to the training set.
