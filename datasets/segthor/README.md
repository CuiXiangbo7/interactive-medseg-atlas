## 🧾 Dataset overview

SegTHOR is a thoracic CT benchmark for delineating four structures relevant to radiotherapy planning: heart, aorta, trachea, and oesophagus. The challenge separates a training phase from an evaluation phase; consult the current data page for access to the corresponding files.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
