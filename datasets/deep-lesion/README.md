## 🧾 Dataset overview

DeepLesion is a large-scale CT collection of radiology lesions mined from clinical reports and marked with image-level and lesion-level information. The official download page is hosted by the US National Institutes of Health.
> **Source note:** The linked Box page requires browser JavaScript for its full contents; use the NIH download page and cited paper for release details.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
