## 🧾 数据集简介

DeepLesion 是从临床报告中整理的大规模 CT 病灶集合，包含影像级和病灶级信息。官方数据下载页面由美国国立卫生研究院托管。
> **来源说明：**所链接的 Box 页面需要浏览器 JavaScript 才能完整显示；发布详情请查阅 NIH 下载页和引用论文。

论文条目影像数与官方发布范围分开记录。本图谱不镜像托管影像或掩膜文件。
