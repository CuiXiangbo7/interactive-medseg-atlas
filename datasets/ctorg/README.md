## 🧾 Dataset overview

CT-ORG is a TCIA collection of 140 CT volumes with organ masks. The official record describes five structures across all cases and brain labels only in the subset where the brain is visible; scans include varied coverage, contrast, and acquisition protocols.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

The TCIA release contains 140 CT scans: 119 training and 21 test scans. Of the 140 images, 131 are dedicated CT studies and nine are CT components of PET/CT exams.
