## 🧾 Dataset overview

M-CRIB is a neonatal brain MRI atlas with manually delineated anatomical structures. It was designed to provide a neonatal reference space and labels for structural segmentation and registration research.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
