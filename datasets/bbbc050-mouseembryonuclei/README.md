## 🧾 Dataset overview

BBBC050 provides fluorescent 3D time-series images of early mouse embryos with alternative nucleus-reference annotations. The dataset can be used to study nuclei segmentation under dense and changing cellular arrangements.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
