## 🧾 Dataset overview

PleThora is a TCIA dataset of pleural-effusion and thoracic-cavity segmentations on diseased-lung CT. Its record reports 402 scans and describes the labels as support for chest-volume localization and preprocessing.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.

## 🗂️ Official release and split

TCIA reports 402 CT scans with left and right thoracic-cavity segmentations; the associated lesion labels include lung parenchyma, tumour, atelectasis, adhesions, and effusion.
