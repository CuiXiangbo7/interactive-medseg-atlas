## 🧾 Dataset overview

The official Zenodo release contains 298 clinical MRI studies with segmentation masks for 56 anatomical structures. The record notes varied pathologies, scanners, sequences, and institutions.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
