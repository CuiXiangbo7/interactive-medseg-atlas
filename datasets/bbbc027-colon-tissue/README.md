## 🧾 Dataset overview

BBBC027 is a synthetic 3D fluorescence-microscopy collection of colon-tissue images with binary cell ground truth. It is a microscopy benchmark rather than a clinical radiology cohort.

The paper-entry image count is shown separately from the official release scope below. Dataset files are not mirrored in this atlas.
